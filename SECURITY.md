# Security

Pikker is experimental, without a guaranteed security-support window. Check release origin and hashes.
Report vulnerabilities privately through GitHub Security Advisory "Report a vulnerability" when available.
If unavailable, open an issue requesting a private contact, without exploit details or credentials.

Never post LCU tokens, lockfiles, player captures, account identifiers or profile/cache files.
Pikker uses strict TLS, fixed loopback LCU access and redacted credentials. Do not disable TLS validation,
antivirus or elevate the application routinely to bypass warnings.
